# Homepage concepts

`homepage-concepts.html` holds five homepage directions for tibi-lab.com: Doors, Nordic Index, Pinboard, Loud Type and Lab Notebook. Open it in a browser and use the tabs to switch concepts.

Every concept renders its app list from one data array (`APPS` in the script), so a new app is one more entry. The Apps control shows each layout with 2, 5 or 9 apps; apps marked "Example" are invented placeholders. The Phone toggle previews the mobile layout.

These are mockups only. Links inside them are placeholders.
